# 《剑与魔法·战旗》剧情总纲

> 编剧笔记 · 五幕三十章主线 + 十二条支线 · 供审阅与扩展

---

## 一、核心主题

**「火焰烧掉的是王座，烧不掉的是人心。」**

复国只是外壳。真正的故事是：**一个亡国公主在复仇与守护之间的成长**，以及围绕"旧王朝为何而灭"层层揭开的真相——灭国不是突发，而是二十年前一场被掩埋的「献祭」埋下的因。每个主要角色都与这场旧案有一根看不见的线。

---

## 二、世界观骨架(铺垫用)

- **瓦伦西亚王国**：立国三百年,王都「晨曦城」。王室血脉相传「聆火之仪」——能与地脉之火共鸣。
- **月神教团**：守护「月之圣典」的隐世教团,记录着地脉的秘密。圣典预言：地脉之火每三百年枯竭一次,需以「王血」重燃,否则大地荒芜、魔物横行。
- **黑曜会**：潜伏的秘社,信奉「以一地之火,换万世之安」。二十年前他们策划了第一次献祭——烧的是当时还是太子的国王之兄（莉拉的伯父）。
- **地脉之火**：王国的命脉,也是全篇的核心悬念。它正在枯竭——这才是灭国的真正动机（黑曜会要逼王室献祭重燃地火）。

> **关键铺垫**：开场不是"叛军突然破城"。第一章前的序章,就通过米拉的口,埋下"地脉之火异常""教团圣典失窃一页"两条线。灭国是有人处心积虑二十年的结果。

## 三、主要角色与暗线

| 角色 | 表面 | 暗线（伏笔） |
|---|---|---|
| **莉拉** 公主 | 复国 | 她是「王血」,黑曜会真正的目标。母亲临终把半块「聆火印」塞进她手中（第三章揭示） |
| **加勒特** 佣兵 | 报恩护送 | 二十年前献祭夜,他是守城的少年兵,亲手没能拦住那场火——护送莉拉是赎罪 |
| **米拉** 教团少女 | 同行 | 教团圣典失窃的那页,正是"献祭之法"。她要找回那一页,却逐渐发现自己师父就是黑曜会内应 |
| **塞拉菲娜** 贤者 | 月之魔法助力 | 她是当年被献祭的伯父之女——莉拉的堂姐,隐姓埋名归来,立场在"助莉拉"与"恨王室"之间摇摆 |
| **鲁克** 斥候 | 断桥被俘归顺 | 他本是黑曜会底层棋子,亲眼见过献祭名单上有自己的名字,故倒戈。后期为护莉拉重伤 |
| **奥伯龙** 黑曜会主祭 | 灭国元凶 | 曾是王兄（伯父）的挚友。献祭王兄时他动摇过,如今用同样的手法逼莉拉,是想证明"当年没有选择" |
| **卡西安** 摄政王 | 开城的"叛臣" | 表面开城投敌,实则是王兄旧部,潜伏二十年只为保住"王血"莉拉。中期反转的关键 |

## 四、五幕结构(30 章主线)

### 第一幕 · 灰烬(序章~第6章)「为什么是我们」
> 灭国当夜→逃亡→第一次直面"这不是普通的叛乱"。

- **序章 逃亡之夜**：王都陷落当夜。铺垫：米拉提到"地脉之火昨夜突然变成青色，教团典籍说这是'饮血之兆'"。
- **第1章 断桥**：遇黑袍杀手,对方不劫财只问"公主人头"。埋下"有人要买王血"。
- **第2章 三岔口**：抉择(霜峰/河谷)。无论哪条,都遇到黑曜会的"猎火者"。
- **第3章 母亲的首饰盒**：莉拉在逃难队伍中认出母亲的旧仆,得到半块「聆火印」与一句遗言——"别让它重燃,孩子,那火要的是你的命。"
- **第4章 古战场**：(可接支线)加勒特认出二十年前献祭的旧地,首次吐露那晚真相的一角。
- **第5章 月神神殿**：米拉回教团废墟寻圣典,发现失窃一页的抄录——"以王血引地火"。
- **第6章 猎火令**：黑曜会正式亮旗,悬赏"王血"。第一幕boss：猎火者队长。

### 第二幕 · 暗流(第7~12章)「每个人都有秘密」
> 组建反抗军,盟友各怀心思。

- **第7章 流亡者营地**：收拢残兵与难民。塞拉菲娜登场（"偶然"路过相助）。
- **第8章 摄政王的书信**：卡西安"叛臣"送来密信劝降,莉拉怒撕,加勒特却觉蹊跷。
- **第9章 米拉的师父**：米拉发现教团内应是自己的师父。师徒对决前的挣扎。
- **第10章 第一次攻城**：反抗军夺下第一座小城,代价惨重。主题：复国的血。
- **第11章 塞拉菲娜的刺青**：鲁克认出塞拉菲娜颈后的旧王室纹印。堂姐身份将揭。
- **第12章 真假王血**：黑曜会抓错人（抓了侍女假扮的"公主"）,莉拉意识到对方要的只是"血脉"而非"她"。

### 第三幕 · 真相(第13~18章)「二十年前那场火」
> 揭开灭国与献祭的真相,盟友信念受冲击。

- **第13章 卡西安的牢狱**：卡西安"被俘",实为借囚见莉拉,道出二十年前献祭全程。
- **第14章 伯父的女儿**：塞拉菲娜身份揭晓。她举剑指向莉拉又放下——"我恨的不是你,是那把火。"
- **第15章 圣典失页**：米拉夺回失窃圣典一页,发现"献祭"其实是黑曜会篡改的伪法——真正的聆火之仪不需王血。
- **第16章 奥伯龙的过去**：通过卡西安之口,揭示主祭奥伯龙当年是王兄挚友,献祭夜的动摇与堕落。
- **第17章 地脉枯竭**：大地开始荒芜,魔物涌现。印证"地火将熄",双方都被逼到墙角。
- **第18章 加勒特的债**：加勒特向莉拉坦白二十年前守城失职。莉拉："你欠我伯父一条命,就用护我一生来还。"

### 第四幕 · 抉择(第19~24章)「要不要点那把火」
> 地火将熄,点(牺牲王血)与不点(大地荒芜)的两难。

- **第19章 荒芜之地**：目睹地火枯竭的惨状,民心开始动摇——"公主为何不肯牺牲？"
- **第20章 分裂**：反抗军内部因"要不要献祭"分裂。鲁克重伤护莉拉。
- **第21章 第三条路**：塞拉菲娜提出月之魔法或能替代王血——但成功率未知,失败则地火永熄。
- **第22章 黑曜会的邀请**：奥伯龙约莉拉密谈,献出"当年真相"换取她自愿献祭。莉拉险些动摇。
- **第23章 卡西安之死**：卡西安为掩护莉拉撤离而死,临终："我守了二十年的,不是王座,是那句'别让火再烧到孩子'。"
- **第24章 塞拉菲娜的选择**：堂姐决定以自身（同为王血）做月之仪式的引子,把生的机会让给莉拉。

### 第五幕 · 重燃(第25~30章)「火焰的新意」
> 终局。不是复国,而是改写"火"的意义。

- **第25章 兵临晨曦城**：反攻王都前夜,众人诀别与托付。
- **第26章 旧王宫**：在燃烧的废墟中穿行,每个角色与过去告别(蒙太奇式多线对话)。
- **第27章 奥伯龙的祭坛**：直面主祭。奥伯龙揭示他真正的执念——"我不是要毁灭,我只是想证明当年的火没有白烧。"
- **第28章 月与火**：塞拉菲娜启动月之仪式,莉拉以王血共鸣相辅,两脉合一。仪式之战(防守关)。
- **第29章 奥伯龙的终局**：仪式成功,地火以新法重燃。奥伯龙在明白自己错付二十年后,自我了断或被击败,临终解脱。
- **终章 晨曦重燃**：不重建旧王朝,而是建立"不再有献祭之火"的新秩序。各人归宿。尾声：地脉之火静静燃烧,颜色温暖如常。

## 六、叙事节奏与铺垫技巧(写作规范)

1. **每章进场(_enter)**：交代"我们为何到这里"+"本章会发生什么悬念",2~6 句。
2. **战场对话(_battle)**：进入战斗即弹的简短对话,1~3 句,多为临场反应/敌人挑衅,不做长篇。
3. **每章过场(_clear)**：收束本章 + 抛出下一章钩子,2~5 句。
4. **伏笔三原则**：① 开场序章就埋"地火异常""圣典失页"两条主线伏笔;② 每个角色的秘密都提前至少 3 章给暗示(塞拉菲娜纹印第11章暗示、14章揭晓);③ 反派动机(奥伯龙)在第16章先让读者同情,第27章再直面。
5. **灭国不突兀**：序章的夜,通过"地火变青""教团典籍预言""黑袍人不劫财只问人头"三个细节,让玩家第一章结束就意识到"这不是普通叛乱"。
