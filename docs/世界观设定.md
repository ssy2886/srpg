# 《剑与魔法·战旗》世界观设定集

> 剧本的"根"。所有剧情对白、势力冲突、人物动机,都以此为依据。
> 写给玩家看的版本在剧情中分段呈现;本文是创作者的完整底稿。

## 一、大陆 · 艾尔登(Elden)

艾尔登大陆被一条纵贯南北的**地脉**贯穿,地脉中流淌着**地火**——一种维系万物生机的能量。三百年前,先民在地脉源头建立**瓦伦西亚王国**,以"聆火之仪"与地火共鸣,换来三百年风调雨顺。

大陆的秩序,建立在"火"上;大陆的灾祸,也源于"火"。

```
                北 · 霜峰山脉(终年积雪)
                    │
   西 · 风语草原 ────┼──── 东 · 苍梧林海
   (游牧部落)        │        (月神教团圣地)
                    │
              【晨曦城·王都】←── 地脉源头
                    │
   西南 · 断桥隘口 ──┤
   (王国门户)        │
                    │
                南 · 聆火地宫(地脉之心)
```

### 主要地缘
| 地名 | 说明 |
|---|---|
| **晨曦城** | 瓦伦西亚王都,地脉源头所在,聆火地宫在其下。王国的心脏。 |
| **断桥隘口** | 西南门户,一桥横绝峡谷,历代兵家必争。 |
| **霜峰** | 北方雪山,通往王都的险径,常年冰封。 |
| **苍梧林海** | 东方古林,月神教团圣地「苍梧神殿」所在。 |
| **风语草原** | 西部游牧部族之地,骁勇善战,墙头草。 |
| **聆火地宫** | 王都城下,地脉之心的祭坛,聆火之仪举行地。 |

## 二、四大势力

### 1. 瓦伦西亚王国(正统 · 衰落中)
- **领袖**:老国王 **奥斯温**(莉拉之父,序章病逝→被毒杀)。
- **立国之本**:王室血脉能与地火共鸣("聆火"),是大陆名义上的共主。
- **现状**:老国王晚年昏聩,朝政被**摄政议会**把持。地火三百年来首次衰减,天灾频发,民怨四起。王国已是外强中干。

### 2. 黑曜会(篡权者 · 本作主反派)
- **领袖**:大祭司 **奥伯龙**。
- **起源**:二十年前由一群研究地火的学者组成,主张"地火属于全大陆,不应被王室垄断"。
- **堕落**:发现地火衰减后,奥伯龙篡改古籍,伪造"以王血献祭可重燃地火"的伪法——**真实目的**:借"拯救大陆"之名,弑君夺权,让黑曜会取代王室掌控地火。
- **手段**:二十年前毒杀王储(莉拉伯父),如今毒杀老国王、扶持傀儡、血洗王都,都是为了夺取"王血"做祭品。

### 3. 摄政议会(投机者 · 墙头草)
- **领袖**:摄政王 **卡西安**(表面)。
- **构成**:王都贵族与地方领主。老国王昏聩后实际掌权。
- **立场**:谁强附谁。黑曜会政变时,多数议员献城投降换取保全。卡西安表面附逆,实为王室旧臣,隐忍图存。

### 4. 月神教团(守秘者 · 中立)
- **圣地**:苍梧神殿。保管记录地火真相的**月之圣典**。
- **使命**:守护"聆火之仪"的真相——**真正的仪式从不需要活人献祭**。
- **分裂**:大祭司被黑曜会收买,撕走圣典记载真相的一页。米拉因此下山寻回圣典失页。

## 三、编年史(因果链)

| 时间 | 事件 |
|---|---|
| **三百年前** | 先民建瓦伦西亚,以聆火之仪与地火共鸣,大陆丰饶。 |
| **二十年前** | 地火首次衰减。黑曜会散布"王室血祭方能续火"的谣言。王储(莉拉伯父)查地火真相,被黑曜会**毒杀并伪造成"献祭"**。卡西安目击,隐忍。 |
| **三个月前** | 地火再度衰减,灾荒四起。黑曜会借机发难,毒杀老国王奥斯温。 |
| **序章当夜** | 黑曜会发动政变,血洗王都,扶持傀儡政权,宣称"王室血脉断绝,天命已改"。莉拉在忠心护卫下逃出。 |
| **主线** | 莉拉流亡→集结反抗军→揭开二十年前与当夜的真相→夺回王都→以真正的聆火之仪重燃地火。 |

> **关键**:灭国不是"突发"。是黑曜会**酝酿二十年**的夺权——先杀王储,再弑君,再血洗王都,一步步清除王室血脉,只为用"王血"完成他们伪造的献祭,从而名正言顺地掌控地火。

## 四、主要人物志

### 我方

**莉拉(Lyra)· 流亡公主**
- 18岁,奥斯温王独女,瓦伦西亚最后的王血。
- 自幼被父王保护在深宫,不谙世事却心怀仁慈。亡国之夜从"被保护的公主"被迫成长为"扛起复国的人"。
- 弧光:从"想为父报仇"到"想终结这吃人的火",明白真正的王不是血脉,而是守护。

**加勒特(Garrett)· 赎罪佣兵**
- 32岁,前王国近卫,现为佣兵。
- **二十年前**,他是守卫王储的少年兵,亲历王储被"献祭"的那夜,因恐惧没有阻止。此后离队流浪,背负二十年的愧疚。
- 亡国夜救下莉拉,一半是报恩(老国王曾赦免他的逃兵罪),一半是赎罪——这一次,他绝不再退。

**米拉(Mira)· 寻典者**
- 17岁,月神教团修女。
- 师父(教团大祭司)被黑曜会收买、撕走圣典失页。米拉不懂师父为何背叛,下山寻找失页,也为寻找"师父还是不是那个教我'圣典不可违'的人"的答案。
- 冷静、爱提问,是队伍里最早嗅到"政变不对劲"的人。

**塞拉菲娜(Seraphina)· 复仇者**
- 24岁,精通月之魔法的流浪贤者。
- **真实身份**:二十年前被"献祭"的王储之女,莉拉的堂姐。幼时被忠仆救出,隐姓埋名。
- 她归来本为复仇——既恨黑曜会,也曾恨"独活"的王室。在莉拉身上看到同样的命运后,仇恨动摇,最终选择守护而非复仇。

**鲁克(Rook)· 倒戈者**
- 25岁,黑曜会底层猎火者。
- 在黑曜会的"祭品名单"上见过自己的名字——原来底层信徒也不过是随时可弃的"血料"。断桥之战被俘,为求生、也为报复黑曜会的利用,倒戈加入。

### 敌方

**奥伯龙(Oberon)· 大祭司**
- 55岁,黑曜会大祭司,本作主反派。
- **二十年前是王储的挚友**,共同研究地火。王储发现"地火衰减是自然周期,无需献祭"的真相,触动了奥伯龙"借地火夺权"的野心。
- 他亲手毒杀挚友并伪造成献祭。此后二十年,他必须不断告诉自己"当年别无选择",否则无法面对亲手杀死挚友的事实。
- 如今逼莉拉献祭,既是夺权,更是想**证明当年杀死挚友是"对的"**——一个用二十年自我欺骗堆砌起来的悲剧。

**卡西安(Cassian)· 摄政王**
- 48岁,王都摄政王,表面附逆的"开城叛臣"。
- **真实身份**:王储旧部。二十年前目击王储被害,却无力阻止,从此隐忍布局,只为保住王室最后的血脉。
- 献城投降是为麻痹黑曜会,暗中保护聆火地宫、维系忠王势力。中期身份揭晓,为护莉拉撤离而死——用一生守住了对王储的承诺。

## 五、写作规范(剧情对话必须遵守)

1. **每段对话都要回答"为什么"**:这场战斗因何而起?对方为何在此?我方为何必须打?
2. **势力动机先行**:黑曜会的每一步(夺城/追捕/献祭)都要让玩家理解其"夺地火"的逻辑,不是"坏人做坏事"。
3. **伏笔前置**:重大反转(塞拉菲娜身份/卡西安忠良/献祭真相)至少提前3章给暗示。
4. **人物有"私"**:每个角色的行动都有私人动机(加勒特赎罪/米拉寻师/塞拉菲娜复仇),不只服务于主线。
5. **对白即叙事**:背景故事不单独"讲",而融入对话——通过角色的争执、回忆、质问自然带出。
