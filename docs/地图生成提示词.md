## 提交方式
1. 按上表逐章生成（或一次批量）
2. 图发我，或放入 `assets/maps/{章节id}.jpg`
3. 我会给该章地图 JSON 加 `bg_image` 并按图微调格子地形

**没有背景图的章节会自动用程序化彩色方块地形兜底**，游戏始终可玩；配图后画质升级。
